# Tier-B replication notebooks

One self-contained, executable Jupyter notebook per `sp.replicate` paper. Open
any notebook and **Run All** to reproduce the paper's headline number from the
bundled *real* data — no external downloads, no R/Stata required.

Each notebook ends with a **drift-guard** cell: an `assert` that the estimator
reproduces the pinned value. Executing the notebook therefore *is* a regression
test. `tests/test_replication_notebooks.py` runs all of them headless in CI, so
a numerical drift in `sp.synth` / `sp.rdrobust` / `sp.ivreg` / `sp.regress` /
`sp.match` fails the build.

## Notebooks

| notebook | paper | design | headline reproduced |
|---|---|---|---|
| `01_card_1995_iv.ipynb` | Card (1995) returns to schooling | IV / 2SLS | OLS 0.074, 2SLS 0.132 (Table 2) |
| `02_abadie_2010_prop99_synth.ipynb` | Abadie–Diamond–Hainmueller (2010) Prop 99 | synthetic control | post-1989 ATT ≈ −19.8 packs/capita (Fig 2 ≈ −19) |
| `03_lalonde_1986_nsw_matching.ipynb` | LaLonde (1986) / Dehejia–Wahba (1999) NSW | matching / OLS | naive −$635, adjusted +$1,548, PSM ≈ +$1,963 vs experimental ≈ $1,794 |
| `04_lee_2008_senate_rd.ipynb` | Lee (2008) Senate RD | regression discontinuity | conventional jump 7.41 pp (SE 1.46) at CCT bandwidth |
| `05_graddy_2006_fish_iv.ipynb` | Graddy (2006) Fulton Fish Market | IV / 2SLS | wave-height IV recovers true elasticity ≈ −0.95 |

Two `sp.replicate` keys are intentionally **not** notebook-ified:

- `angrist_pischke_mhe` — a textbook reference with no single bundled dataset.
- `graddy_2006` ships a *simulated* deterministic replica (the original data
  lives on Graddy's website), so notebook 05 is a known-truth IV demo rather
  than an original-data parity claim. It is included because it still exercises
  a real estimator against a known answer.

## Run

```bash
pip install -e ".[notebooks]"          # nbformat + nbclient + nbconvert + ipykernel

# Regenerate the .ipynb from the single source of truth:
python scripts/build_replication_notebooks.py
#   or:  make -C Paper-JSS notebooks

# Execute them headless (drift guard):
pytest tests/test_replication_notebooks.py -q --no-cov
#   or:  make -C Paper-JSS notebooks-execute
#   or:  jupyter nbconvert --execute --to notebook --inplace <notebook>.ipynb
```

## Provenance and the LaLonde PSM pin

The notebooks are generated by `scripts/build_replication_notebooks.py`; the
numeric anchors were verified to reproduce on the bundled real data at the
v1.16.1 source tree. Card, ADH (2010), and Lee (2008) reproduce their pinned
StatsPAI values to ≤ 1e-3 / 0.5 / 1e-2 respectively.

For LaLonde, `sp.match(method='nearest')` is **deterministic** but its 1:1 NN
PSM ATT is sensitive to tie-breaking on the binary covariates (`black`,
`hispanic`, `married`, `nodegree`); a tie-handling change since the original pin
moved it from ≈ $2,012 to ≈ $1,963 (a 2.5% shift, no nondeterminism). The
notebook's drift guard therefore pins the **robust scientific claim** — matching
recovers the ≈ $1,794 experimental benchmark and removes the negative naive
selection bias — rather than a brittle dollar value. The stale $2,012 figure in
the `sp.replicate('lalonde_1986')` teaching registry is tracked as a
documentation correction outside the JSS validation-evidence claim; the
replication notebook pins the current $1,963 value.
