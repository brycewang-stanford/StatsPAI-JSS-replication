\section{Worked examples}\label{sec:examples}

The seven worked examples show how the package is used and test the validated
core end to end. They are not seven miniature empirical papers. Each has
an executable script under \code{Paper-JSS/replication/} that writes the
JSON, table fragments, and figures the build reads
(Table~\ref{tab:worked-example-map}). The staggered-DiD example is the
main case study.

Two kinds of data appear, and the paper keeps them apart. An
\emph{original extract} is a public data set as a reference package ships
it. A \emph{calibrated replica} is simulated data tuned to the published
moments of such an extract, so that it can be redistributed; several
\code{sp.datasets} loaders return one by default and warn that they do. A
replica supports statements about software agreement, not about the
original study. Its numbers differ from the original's, sometimes
substantially, and this paper never quotes one against the other.

Card's published 0.075 and 0.132 come from a longer specification with
\code{smsa66} and region dummies, on which the full extract gives 0.0747
and 0.1315 in \proglang{R} (\path{replication/scripts/ex01_card_long_spec.R}). The shorter specification here gives
\(\hat\beta_{\mathrm{OLS}} = 0.07401\) and
\(\hat\beta_{\mathrm{IV}} = 0.1323\). \proglang{R}'s
\code{lm}+\pkg{sandwich} and \pkg{AER}\code{::ivreg} return the same two
coefficients on the same CSV at relative errors
\(7.9\times 10^{-15}\) and \(1.6\times 10^{-11}\)
(Table~\ref{tab:headline-parity}).

The audit separates three states that a flat checklist would merge. The
first-stage \(F\) of 16.72 clears the \(F>10\) rule of thumb
\citep{staiger1997instrumental,stock2005testing}. ``Passed'' means only
that this screen was met, which is why weak-instrument-robust
Anderson--Rubin inference is still listed as missing. The
over-identification test is not applicable, not missing. With one
endogenous regressor and one excluded instrument the Sargan/Hansen
statistic has zero degrees of freedom. The audit reads those counts from
the fitted object.

The four fits do not share one identification argument. The 2SLS
coefficient uses \code{nearc4} as an excluded instrument and, with
heterogeneous returns, identifies a local average effect for compliers
under relevance, exclusion, independence, and monotonicity. The DML and
forest calls use no instrument. They are causal only under conditional
exogeneity of schooling, the assumption the IV design exists to avoid, so
here they estimate an adjusted association. The DML interval also uses the default
learner, which under-covers on the design of Section~\ref{sec:track-b}
(0.883 at nominal 0.95), so that column shows the interface and is not a
recommended final estimate.
Listing~\ref{lst:card-cate} summarizes how that association varies.

Because schooling is continuous, the forest's scalar aggregate is the
average partial effect from the continuous-treatment debiased score, not
the binary augmented inverse-probability-weighting (AIPW) aggregate of the
coverage study. \code{cf.average\_treatment\_effect()} returns \(0.0787\)
(standard error, SE, \(0.0049\)), and so does \pkg{grf}~2.6.1 on the same
data. That is one draw per engine, not a grade. Both packages refuse the
ATT and ATC targets here.

\subsection{Abadie--Gardeazabal (2003): the Basque country}\label{sec:ex-basque}

The Basque example \citep{abadie2003economic} shows why a synthetic-control
(SCM) number must travel with its specification and its data.
Table~\ref{tab:basque-specs} lists the four combinations used in this
article. \code{Synth::synth} implements the specification of
\citet{abadie2010synthetic} (ADH), with one special predictor per
pre-treatment year and a nested search over the predictor weights \(V\).
Under it the three implementations nearly coincide on the original data
(row~1) and split on the calibrated replica (row~2), the paper's one
disclosed reference disagreement (Section~\ref{sec:scm-identification}).
The solver is checked where the answer is unique (row~4). The package
default (row~3) uses the pre-treatment outcome path as predictors, where
\(V\) is not identified and is set to the identity. That default is a
convention with no reference row on these data.
Listing~\ref{lst:basque} runs row~1, and Figure~\ref{fig:basque-gap} draws
its gap.

\subsection[Callaway-Sant'Anna staggered DiD: mpdta]{Callaway--Sant'Anna staggered DiD: \texttt{mpdta}}\label{sec:ex-csdid}

This example carries one fitted object from estimation through
aggregation and sensitivity, on the original \code{did::mpdta} data, a
county panel of teen employment and minimum-wage increases.
Listing~\ref{lst:csdid} shows the calls. They read the copy in the
replication archive; \code{sp.datasets.mpdta(simulated = False)}
downloads the same data, and the default \code{sp.datasets.mpdta()}
returns a calibrated replica.

% A float, so the listing and its caption always share a page (inline, a
% page break stranded the last argument line and the caption).
\begin{lstlisting}[float=tb,caption={Callaway--Sant'Anna fit, simple and
event-study aggregation, Rambachan--Roth bounds from the same fitted

                          id = "countyreal", g = "first_treat",
                          control_group = "nevertreated",
                          estimator = "reg")

mpdta["post"] = ((mpdta["first_treat"] > 0) &
                 (mpdta["year"] >= mpdta["first_treat"])).astype(int)

Writing \(\delta_t\) for the differential trend of treated and
comparison units in period \(t\) (in years), the smoothness restriction
of \citet{rambachan2023more} is
\begin{equation}\label{eq:delta-sd}
  \Delta^{SD}(M) = \bigl\{\delta : \bigl|(\delta_{t+1}-\delta_t) -
  (\delta_t-\delta_{t-1})\bigr| \le M \ \text{for all } t\bigr\},
\end{equation}
so \(M\) bounds how much the slope of the differential trend may change
from one year to the next, in log points per year per year. \(M=0\)
allows only a linear continuation of the pre-treatment trend. The
simple ATT and the event-time effects equal \pkg{did}'s on these data, at
relative errors of \(10^{-14}\) (Table~\ref{tab:headline-parity}).
Table~\ref{tab:handoff} reports every post-treatment period. The effect
at \(e=0\) does not exclude zero even at \(M=0\). The later effects do, and
their breakdown values, the largest \(M\) at which the interval still
excludes zero, are small relative to the largest second difference of the
pre-treatment path (0.024), so these effects are sensitive to modest departures
from a linear trend. \code{sp.callaway\_santanna} defaults to a universal base
period, which this restriction needs, where \pkg{did} defaults to varying;
post-treatment effects are unaffected. At \(M=0\) the native intervals
agree with \proglang{R} \pkg{HonestDiD} 0.2.8 on the same coefficients and
covariance within \(10^{-4}\); that package simulates its folded-normal
quantile (Section~\ref{sec:track-a}).

The right-hand columns of Table~\ref{tab:handoff} show why these
quantities should come from the fitted object. The Rambachan--Roth
interval needs the \emph{joint} covariance of the event-study coefficients.
Composed by hand, the workflow extracts it from one package's aggregation
object and enters it into another's sensitivity function. A careful user
of \pkg{did} and \pkg{HonestDiD} does this correctly. The hand-off also
offers a shortcut that runs without complaint, which is to rebuild the
covariance from a table of standard errors. The coefficients are
correlated up to \(0.76\) among the pre-periods and up to \(0.24\) in
magnitude across the pre- and post-periods. With the diagonal in place of
the joint covariance, the intervals at \(e=1\) and \(e=3\) no longer exclude
zero, so the shortcut reverses the conclusion in two of four periods. The
direction is not general. On a calibrated replica the same shortcut
overstated the breakdown value at \(e=0\) by 26\%. This illustrates a
hazard of a hand-off. It does not measure what careful users obtain.

In \statspai{}, \code{sp.honest\_did} reads the joint covariance, the
relative times, and the aggregation weights from the fit through one
extractor, \code{sp.event\_study\_vcov}, which nine event-study estimators
share. When a fit has no joint covariance the native path refuses to build
one from standard errors. \code{sp.event\_study\_vcov} itself returns a
diagonal by default in that case, with a warning and \code{joint=False}, and
\code{allow\_diagonal=False} raises. A single entry point lets a fix reach every
caller of that extractor, as the 1.30.0 repair of the cohort-share term did; a
separate path, repaired in 1.31.0, shows the limit
(Table~\ref{tab:correctness-history}). The standard error in
Listing~\ref{lst:csdid-output} is the analytic influence-function one.
\code{sp.callaway\_santanna} defaults to it where \pkg{did}'s
\code{att\_gt} defaults to a multiplier bootstrap, and \code{sp.aggte}
inherits the fit's setting, as \code{did::aggte(bstrap = NULL)} does. The
printed value is therefore deterministic.

The last block of Listing~\ref{lst:csdid-output} is the
\citet{goodmanbacon2021difference} decomposition of the two-way fixed-effects
coefficient, \(-0.0365\) on these data. Comparisons that use an
already-treated cohort as the control carry 5.4\% of the weight and
comparisons with never-treated counties 86.3\%, which is why that
coefficient sits close to the simple ATT of \(-0.0400\) here. The weights
describe this panel, and a design with few never-treated units would not be
so forgiving.

Figure~\ref{fig:mpdta-es} draws the event study of
Listing~\ref{lst:csdid}. On the calibrated replica of the parity study,
\statspai{}, \pkg{did}, and \code{csdid} agree on the simple ATT
\(-0.0329765\) and to \(4\times10^{-15}\) on its analytic SE. The test suite
also checks on a homogeneous replica that Callaway--Sant'Anna, Sun--Abraham
\citep{sun2021estimating}, imputation \citep[BJS;][]{borusyak2024revisiting},
and DR-DiD \citep{santanna2020doubly} collapse to the same estimand when
their identification restrictions coincide.

\subsection{Regression discontinuity, matching, and a causal time series}\label{sec:ex-rd}\label{sec:ex-lalonde}\label{sec:ex-causal-impact}

Listing~\ref{lst:other-calls} shows the calls of the remaining designs.
The RD data are the public \code{rdrobust::RDsenate} extract, a U.S.\
Senate margin-of-victory sample with a sharp design in the style of
\citet{lee2008randomized}. It is not Lee's House data, which we do not
redistribute. The native \code{sp.rdrobust} implements the
\citet{calonico2014robust} (CCT) bandwidth cascade and robust
bias-corrected inference \citep[software article:][]{calonico2015rdrobust}.
It returns \proglang{R} \pkg{rdrobust}'s mean-squared-error optimal
bandwidth (17.7544) and its conventional and robust estimates at relative
error below \(3\times10^{-13}\). \code{bwselect = "cct"} delegates instead to the authors' official
\proglang{Python} port, which agrees to \(2\times10^{-13}\) at version 2.0.0,
a convergence check and not parity.

\Needspace*{15\baselineskip}
\begin{lstlisting}[caption={Calls of the RD and matching examples. The
matching covariates are those of \citet{dehejia1999causal}, and \code{sp.psm}
names the treatment \code{d} and the covariates \code{X}.},label={lst:other-calls},captionpos=b]
>>> senate = sp.datasets.lee_2008_senate(simulated = False)
>>> rd = sp.rdrobust(senate, y = "y", x = "x", c = 0)
>>> round(rd.estimate, 4), round(rd.se, 4)
(7.5065, 1.7413)
>>> nsw = sp.datasets.nsw_lalonde()
>>> covs = ["age", "educ", "black", "hispanic", "married", "nodegree",
...         "re74", "re75"]
>>> att = sp.psm(nsw, y = "re78", d = "treat", X = covs, method = "nn")
>>> round(att.estimate, 2), round(att.se, 2)
(1968.8, 1178.21)
\end{lstlisting}

The LaLonde \citep{lalonde1986evaluating} / Dehejia--Wahba
\citep{dehejia1999causal} workflow compares an experimental benchmark with
an observational comparison. On \code{causalsens::lalonde.psid}
\citep{blackwell2014selection}, the naive OLS ATT is \(-\$15{,}200\) in
both \statspai{} and \proglang{R}, and the covariate-adjusted OLS ATT is
\(\$751.9\) on both sides. On \code{MatchIt::lalonde}, 1:1
nearest-neighbour matching differs from \pkg{MatchIt} by 1.9\% (1{,}969
against 2{,}007), because the two break tied nearest controls differently.
That row is a reported difference, not parity. It compares two matching
programs and does not test recovery of the experimental estimate.

The causal-impact example uses a deterministic simulated advertising lift
in the style of \citet{brodersen2015inferring}. The known post-intervention
lift is \(4.2\) sales units per day. The call is
\code{sp.causal\_impact(df, y = "sales", time = "day", intervention\_time = 61,
covariates = controls)} with four unaffected control series, and it estimates
\(4.306\) with SE \(0.125\), a 95\% interval \([4.055,4.556]\), and a
pre-period root mean squared error of \(0.562\). This is a known-truth check,
not a cross-language claim.

\subsection{Three ecosystems, one number: panel counterfactuals and interaction effects}\label{sec:ex-fect}

The last example shows the same estimator returning the same number in
all three languages. It uses two method families whose authors ship
both \proglang{R} and \proglang{Stata} implementations. The first is the
set of counterfactual estimators for time-series cross-sectional data of
\citet{liu2024practical}. In \pkg{fect} these are two-way fixed effects,
interactive fixed effects, and matrix completion, fitted on the
untreated cells. The second is the interaction-effect diagnostics of
\citet{hainmueller2019much}. In \pkg{interflex} these are linear,
binning, and kernel estimators of a conditional marginal effect.
\statspai{} ports both natively. Listing~\ref{lst:fect} runs them on the
data of the two parity modules for these packages, after a \pkg{panelView}-style look at the
treatment pattern \citep{mou2023panel}. The file paths are relative to
the root of the replication archive, and the \code{sp.interflex} call
keeps the argument names of the package it ports (\code{d}, \code{x},
\code{z}).

\Needspace*{26\baselineskip}
\begin{lstlisting}[caption={Panel counterfactuals and interaction
effects. \code{pattern} is \code{(True, False)}, a staggered design without
reversals; \code{att\_by\_period} holds the ATT by relative period, and
\code{p\_linear} is the Wald $p$~value of the linear model against the
binning model.},label={lst:fect},captionpos=b]
import pandas as pd
import statspai as sp

panel = pd.read_csv("tests/r_parity/data/86_fect.csv")
sample = pd.read_csv("tests/r_parity/data/87_interflex.csv")

fig, ax, info = sp.panel_view(panel, id = "id", time = "time",
                              treat = "D")
pattern = info["staggered"], info["has_reversals"]
fe = sp.fect(panel, y = "Y", treat = "D", id = "id", time = "time",
             covariates = ["X1", "X2"], method = "fe")
ife = sp.fect(panel, y = "Y", treat = "D", id = "id", time = "time",
              covariates = ["X1", "X2"], method = "ife", r = 2,
              vce = "bootstrap", n_boot = 200, seed = 0)
mc = sp.fect(panel, y = "Y", treat = "D", id = "id", time = "time",
             covariates = ["X1", "X2"], method = "mc", lam = 0.002)
att_by_period = ife.detail
bins = sp.interflex(sample, y = "Y", d = "D", x = "X", z = ["Z1"],
                    estimator = "binning", cutoffs = [0.3, 1.7])
p_linear = bins.model_info["tests"]["p_wald"]
kern = sp.interflex(sample, y = "Y", d = "D", x = "X", z = ["Z1"],
                    estimator = "kernel", bw = 1.0)
\end{lstlisting}

The agreement below holds at \emph{user-specified} tuning values, the
listing's \code{r = 2}, \code{lam = 0.002}, and \code{bw = 1.0}, fixed so
that all three implementations solve the same problem. \pkg{fect}
cross-validates \(\lambda\) under \code{method = "mc"} and \(r\) when given a
candidate vector, and \pkg{interflex} selects the kernel bandwidth by
cross-validation when none is supplied. \statspai{} ports these selectors
(\code{cv=True}). Their folds are random, so the evidence is weaker. On
identical folds the per-fold scores equal \pkg{fect}'s to
\(5.9\times10^{-8}\) and \pkg{interflex}'s to \(2.8\times10^{-13}\). Across
fold seeds the \pkg{fect} selections coincide, while \proglang{R}'s own
\pkg{interflex} picks spread over six neighbouring grid points, and every
\statspai{} pick lies on the same flat stretch of the loss curve.
