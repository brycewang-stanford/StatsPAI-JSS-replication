\section{Computational details}\label{sec:compdetails}

\statspai{} installs from PyPI without compiled extensions of its own.
Its numerical core runs on the scientific \proglang{Python} stack, and
the only compilation step, \pkg{numba}'s JIT compiler, is optional at
runtime. Every artifact of this article was regenerated in one
environment, recorded exactly in \path{requirements-jss-lock.txt}:
\proglang{Python} 3.10.20 with \pkg{NumPy} 2.2.6, \pkg{SciPy} 1.15.3,
\pkg{pandas} 2.3.3, \pkg{statsmodels} 0.14.6, \pkg{scikit-learn} 1.6.1,
\pkg{linearmodels} 7.0, \pkg{Numba} 0.65.1, and \pkg{matplotlib} 3.10.9
\citep{hunter2007matplotlib}. \path{requirements-jss.txt} states the
supported version ranges and is not the lock. Optional heavy backends
are isolated under extras and are lazily imported. The submitted numerical and timing claims do
not require a compiled Rust extension, GPU, or commercial software.

The \proglang{R} parity harness is pinned by
\path{tests/r_parity/renv.lock}. The reference environment uses
\proglang{R} 4.5.2. The packages behind the twelve-estimator suite are
\pkg{fixest} 0.14.0, \pkg{did} 2.3.0,
\pkg{Synth} 1.1-10, \pkg{synthdid} 0.0.9, \pkg{rdrobust} 4.0.0,
\pkg{rddensity} 2.6, \pkg{HonestDiD} 0.2.8, \pkg{DoubleML} 1.0.2,
\pkg{grf} 2.6.1, and \pkg{MatchIt} 4.7.2. The three-ecosystem worked
example adds \pkg{fect} 2.4.1 and \pkg{interflex} 1.4.0. The lockfile
and the per-row JSON provenance record, with exact versions and GitHub
SHAs, the complete dependency closure for all \RParityModuleCount{}
modules (including \pkg{augsynth}, \pkg{gsynth}, \pkg{lme4}, \pkg{CBPS}
\citep{imai2014covariate}, \pkg{ebal} \citep{hainmueller2012entropy},
\pkg{optmatch} \citep{hansen2006optimal}, \pkg{Matching}
\citep{sekhon2011multivariate}, and \pkg{sbw}
\citep{wang2020minimal}). The Stata bridge uses \proglang{Stata} 18 MP and records
official/community command versions in
\path{tests/stata_parity/STATA_ENVIRONMENT.md}. All \StataParityModuleCount{} R-joined Stata
modules and all \RParityModuleCount{} \proglang{R} modules reproduce their frozen JSON
outputs with zero drift. The Stata leg requires a licence, so the
archive ships the frozen JSONs, matching do-files, and engine provenance,
and the main paper remains auditable from the
\proglang{Python}/\proglang{R} artifacts.

\subsection{Distribution and installation}

The package is distributed through PyPI
(\code{pip install statspai==\StatsPAIVersion{}}). This article
describes release \StatsPAIVersion{} (tag \code{v\StatsPAIVersion{}}),
and the replication archive carries the same source as a snapshot with
its file hashes. Optional extras are exposed as
\code{dev}, \code{performance}, \code{bayes}, \code{deepiv},
\code{neural}, \code{fixest}, \code{rd-cct}, and \code{plotting}
bundles. The \code{rd-cct} extra installs the official \pkg{rdrobust}
\proglang{Python} port (\code{rdrobust>=2.0}, maintained by the
\pkg{rdrobust} authors), which backs the optional \code{bwselect="cct"}
path of Section~\ref{sec:ex-rd}. Because that port is GPL-3 licensed,
it is an opt-in extra that the user installs, not a bundled dependency
of the MIT-licensed core. No parity claim in this paper
depends on it, since the native default selector reproduces its numbers
on the audited fixture without it.

The test suite runs on Linux, macOS, and Windows in continuous
integration; the acceptance evidence for this paper is the Track~A--D
artifacts, worked examples, and audit scripts, each regenerated rather
than quoted.

\subsection{Reproducibility of this paper}\label{sec:reproducibility}

The evidence is rebuilt by one standalone script,
\path{Paper-JSS/replication/reproduce.py}. The script distinguishes two
things a reader might mean by ``reproduced''. Its default licence-free
path, \code{--tier 1}, takes a few minutes on the laptop of
Section~\ref{sec:performance}, well inside an hour. It
runs every generator the manuscript reads, then accounts for each of the
twelve generated inputs of the compiled article, one by one, in
\path{replication/results/reproduce_manifest.json}.
Five are \emph{recomputed} from the installed package on that run: the
figures and tables of the worked examples, every printed listing and
transcript (replayed statement by statement and compared line for line),
the registry census behind every count in the text, and the MCP trace.
Seven are \emph{re-tabulated} from frozen experiment artifacts: the
Track~A and original-data parity tables, the Track~B coverage table, the
forest seed table, and the Track~C table and figure. The frozen
experiments have their own entry points (Table~\ref{tab:reproduction}).
Each writes the artifact its table reads, so a recompute followed by
Tier~1 rebuilds the tables from fresh numbers. A group whose reference
side needs \proglang{R} fails when \proglang{R} is missing instead of
reusing the frozen reference, so fresh \proglang{Python} numbers are
never silently paired with old reference numbers. The timing comparator
likewise refuses rows whose two sides read different input bytes or
came from different runs. The \emph{\proglang{R} path} (\code{--tier 2})
adds the pinned \code{renv} environment and re-executes every
\proglang{R} reference of Track~A on the committed bytes. (Module 81
needs the archived \pkg{DIDmultiplegt}~0.1.4 in a private library, since
the current release returns \code{NaN} on its own example.) Auditing
the parity claim at full strength requires this path. The \emph{\proglang{Stata} path} (\code{--tier 3}) re-executes the
migration bridges and requires a Stata licence.

Tier~1 was verified from a clean start. A fresh virtual environment was
built from the lock and the \code{v\StatsPAIVersion{}} source, in a copy
of the archive whose generated inputs had been deleted first
(\code{--clean}), and it rebuilt all twelve. The Dockerfile pins the
same environment (the \proglang{Python} base image by digest, every
package by the lock), leaving only the \TeX{} system packages that
typeset the PDF unpinned. Both sides of every parity row can also be
re-derived on their own. \path{tests/r_parity/verify_reproduce.py}
re-runs each \proglang{R} reference on the committed bytes, and
\path{tests/r_parity/verify_reproduce_py.py} does the same for the
\statspai{} side, regenerating each fixture CSV byte for byte. All
\RParityModuleCount{} modules clear a \(10^{-9}\) reproduction floor
with no exemptions.
