\subsection{Interface checks}\label{sec:agentbench}

This subsection reports only \emph{mechanical} and \emph{contractual} evidence
that the agent-facing surface is correctly wired. Whether the interface
improves an LLM agent's empirical work is a question that schema coverage
cannot answer, as the last paragraph of this subsection explains.

\paragraph{Mechanical evidence.}\label{sec:agentbench-mechanical}

Table~\ref{tab:schema-coverage} reports schema coverage. All
$\RegistryTotal$ public functions emit a schema, which holds
by construction, since the registry pipes any typed signature into a JSON
Schema. The stronger contract is that every parameter carries a non-empty
description. This table is an internal completeness audit, not a ranking.

A non-empty description does not make a parameter's meaning unambiguous to a
machine. Of the \SuiteSchemaParameters{} parameters of the
\SuiteSchemaEntries{} suite entry points with a schema, \SuiteSchemaEnum{}
declare an enumerated domain and \SuiteSchemaDefault{} a default. Mutually
exclusive options (\code{robust=} and \code{vce=}) and conditions on an
option (a clustered covariance needs a cluster variable) are stated in the
descriptions and enforced at call time. They are not yet expressed in the
schema, which is the next step for this interface.

\paragraph{Contractual trace evidence.}\label{sec:agentbench-procedural}

The MCP server (Section~\ref{sec:mcp}) negotiates the handshake revisions
2024-11-05 through 2025-11-25 and serves the per-request revision 2026-07-28.
The package's own tests, not an external conformance certification, exercise
them. We also execute one deterministic trace through the live server. It
writes a temporary calibrated \texttt{mpdta} replica (so the traced estimate
\(-0.0330\) is the replica value, not the original-data \(-0.03995\)), calls
\code{tools/list}, and fits \code{callaway\_santanna} with
\code{as\_handle=true}. The returned handle goes to \code{audit\_result} and
then to \code{honest\_did\_from\_result}. The trace resolves the returned
citation keys through the MCP \code{bibtex} tool and sends a stale handle to
check for a recoverable \code{isError} envelope with a refit hint

\paragraph{No behavioural benchmark claim.}\label{sec:agentbench-behavioural}

Mechanical and contractual evidence does not answer whether an LLM agent
using this interface produces \emph{better empirical analyses} than one using
\pkg{statsmodels} or \proglang{R} packages. That question requires frozen
model releases, fixed prompts, matched tool budgets, and a scoring rubric, in
the manner of tool-use and holistic LLM benchmarks
\citep{patil2024gorilla,liang2023helm}. The archive
includes
\code{replication/\allowbreak results/\allowbreak agent\_benchmark\_protocol.md}.
It records the matched arms, task families, scoring dimensions, leakage
controls, and minimum report items required before any behavioural claim is
made. The paper makes no such claim.
